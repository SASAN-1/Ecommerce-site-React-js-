# 🚲 Bicycles.NP

A responsive bicycle e-commerce website built with React.js, JavaScript, and CSS.

Bicycles.NP allows users to browse bicycles, view product details, select available sizes, add products to the cart, and manage their cart items through a responsive and user-friendly interface.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- User Registration & login
- Browse bicycle products
- Product details page
- Product size selection
- Add products to cart
- Update cart item quantities
- Remove products from cart
- Cart item count
- Product search/filtering
- Responsive navigation
- Interactive UI components

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS
- React Router
- Redux Toolkit
- React Icons
- Vite
